# TurtleBot 4 Robotics Experiments

Technical documentation for COMPSYS 732 experiments with TurtleBot 4 and ROS 2.

- [Sensor investigation](sensor-investigation/README.md) covers wheel odometry, LiDAR ranging and mapping, and camera-based red marker detection.
- [Autonomous cube finder](autonomous-cube-finder/README.md) covers the ROS 2 controller, SLAM-to-odometry alignment, and the demonstration results.
